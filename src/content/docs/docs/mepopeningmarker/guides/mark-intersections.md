---
title: Mark an intersection
description: A guide on how to place a void.
---

Mark intersections allow you to mark an intersection between a MEP element(Pipe, cable tray) and a structural element such as walls and floors.
The plugin marks the intersection by placing a void in the document.

To place a void
1. Select a MEP element in the document
2. Click on Find & mark intersections button

The plugin will select the size of the void to fit the mep element and the structural element.

# Types of voids

There are 3 types of voids

1. rectangular void
2. round void
3. vertical void

Rectangular and round voids are used to mark intersections with walls.
Vertical voids are used to mark intersections with floors and ceilings.

# Settings

You can change the configuration on how voids are placed in the settings window.
There you can set up a bunch of parameters

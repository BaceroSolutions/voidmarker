## System requirements

- Autodesk Revit 2023, 2024, 2025, 2026 or 2027
- Windows 64-bit
- An internet connection when Revit starts, so your licence can be checked with Autodesk

## Install

1. Open the [MEP Opening Marker page on the Autodesk App Store](https://apps.autodesk.com/RVT/en/Detail/Index?id=7436713805070157386&appLang=en&os=Win64&mode=preview).
2. Sign in with your Autodesk account and download the installer.
3. Close Revit, then run the installer.
4. Start Revit. A **MEPOpeningMarker** tab appears in the ribbon.

:::tip
If the tab doesn't appear, see [Troubleshooting](/docs/mepopeningmarker/troubleshooting/#the-mepopeningmarker-tab-doesnt-appear).
:::

## Free trial and licensing

MEP Opening Marker is licensed through the Autodesk App Store. Your entitlement is checked against your Autodesk account when Revit starts, so make sure you're signed in to Revit with the same Autodesk account you used on the App Store.

Every new user gets a **30-day free trial** with all features. After the trial, a licence costs **€250 per user per year** and includes:

- Unlimited projects
- Pipes, ducts and cable trays
- Linked model support
- Combine voids
- Free updates
- Priority email support

Buy a licence from the [Autodesk App Store](https://apps.autodesk.com/RVT/en/Detail/Index?id=7436713805070157386&appLang=en&os=Win64&mode=preview).

If your licence can't be confirmed, the commands show an **Access Denied** message. See [Troubleshooting](/docs/mepopeningmarker/troubleshooting/#access-denied).

## Void families

You don't need to load any families yourself. The first time a void is placed in a project, MEP Opening Marker loads the families it needs into that project:

- `Rectangular void`
- `Round void`
- `Vertical void`
- `Tag void`

They're Generic Model families, so you can see, filter and schedule them like any other generic model. If a family with the same name is already in the project, that one is used.

## Uninstall

Close Revit, then remove MEP Opening Marker from **Windows Settings → Apps → Installed apps**. Voids already placed stay in your projects.
